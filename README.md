# 威马软件管家

为已适配的威马 Android 6 车机提供触屏软件管理：通过 U 盘启动，完成软件移除、APK 安装、原厂软件恢复，以及威马桌面和 WePlay 的联网更新。

## 主要功能

- **移除软件**：列出允许移除的原厂应用及已安装第三方软件。其它系统、车辆服务和正在使用的基础程序受保护。
- **批量安装**：自动扫描 U 盘根目录 `apk` 文件夹，显示软件说明、版本及已安装状态，勾选后一键安装。
- **原厂恢复**：完整版优先恢复车机保留的系统程序，必要时调用 U 盘内的原厂 APK；原厂音乐和 BTPhone 提供常用恢复入口。
- **联网更新**：手动查询威马桌面和 WePlay 的 GitHub 发布包，校验后更新 U 盘文件。WePlay 按文件名中的 `perf` 数字比较新旧，数字越大越新。
- **空间与进度**：安装页显示车机数据分区剩余空间；底部大字和颜色提示当前处理项、完成项及失败原因。
- **可选清理**：识别历史临时调试文件，先查看清单再选择清理；保留备份、应用数据和正在使用的文件。
- **留在车机**：安装页可将管家留在车机。拔掉 U 盘后，仅保留软件卸载及桌面、WePlay 的联网更新安装功能，不复制整套附带软件。

## 选择哪个包

| 版本 | 附带软件 | 原厂恢复 | 适合场景 |
| --- | --- | --- | --- |
| 完整包 `full` | 默认软件及其它可选 APK，具体清单见 Release | 包含本地原厂恢复包及恢复页面 | 需要完整管理或恢复原厂软件 |
| 精简包 `lite` | ADB 工具、WePlay / DiPlay、威马桌面、ES 文件管理器、强制旋转 | 不附恢复包，不提供恢复页面 | 只安装常用软件、减少 U 盘占用 |

附带应用的版本、测试状态和每次更新内容请查看 [Releases](https://github.com/naojiren/wm-usb-manager/releases)。开发与编译方式见 [构建说明](docs/BUILD.md)。

## 安装到 U 盘并启动

1. 从 [最新 Release](https://github.com/naojiren/wm-usb-manager/releases/latest) 下载 `full.zip` 或 `lite.zip`。不要把 GitHub 的 **Source code** 源码压缩包当作车机安装包。
2. 将压缩包内容解压到 **U 盘根目录**，不要多套一层文件夹。保留启动文件和 `wm_manager` 文件夹完整。
3. 升级旧 U 盘时，先退出正在运行的管家，按包内 **删除旧文件清单.txt** 移除已被替换的旧 APK。覆盖解压不会自动删除旧文件，其它自行添加的软件可保留。
4. 将 U 盘插入已适配的车机，通过原厂 U 盘入口启动。界面先出现，随后扫描软件和安装包，等待扫描完成再操作。
5. 只在停车状态操作。安装高德前先保存需要保留的收藏、账号、设置和离线地图等数据。

根目录结构示意：

```text
U盘根目录/
├─ factorymodel
├─ certificates.xml
├─ yfautorun.sh
├─ yfautorun.md5
├─ apk/                         # 可自行增减待安装 APK
└─ wm_manager/
   ├─ manager.apk
   ├─ start.sh
   ├─ originals.json            # 仅完整版
   └─ original_apks/            # 仅完整版
```

**首次使用请从完整的 U 盘启动流程进入。** 仅手动安装 `manager.apk`，不会自动建立管家需要的提权后台。

## 使用方法

### 第一步：选择要移除的软件

原厂百度地图、语音输入法和 BTPhone 默认勾选，均可取消；其它项目按需选择。第三方软件单独列出，默认不选。确认后点击 **删除已选软件，进入安装**，也可以直接跳过删除。

BTPhone 下方有红色提醒：**蓝牙电话与 CarPlay 的蓝牙音频冲突**。移除后原厂蓝牙电话和拨号入口可能不可用，需要时可使用完整版恢复。普通移除操作保留应用数据及原厂系统 APK。

### 第二步：勾选并安装 APK

默认选择 ADB 工具、WePlay / DiPlay、威马桌面、ES 文件管理器和强制旋转。其它软件自行勾选，再点击 **一键安装已选软件**。

- `apk` 文件夹可自由增减，重新插入 U 盘或点击 **刷新** 后识别。
- 同一软件的多个版本只选一个；不兼容或较旧的安装包会显示原因。
- 可以选择自动授予软件声明的运行时权限；悬浮窗等特殊权限可能仍需在软件或系统中手动开启。
- 威马桌面默认勾选安装到系统分区，可关闭该选项；写入后按提示重启车机生效。
- 安装页顶部的剩余空间还需扣除安装中转、解压和系统预留，不能只按 APK 大小估算。

**高德的安装流程会清除应用数据。** 普通高德签名不兼容时，会完整卸载旧高德后安装选中的新包；系统应用、多用户或状态无法核实时停止处理，不会无限重试。

### 恢复原厂软件（完整版）

进入 **恢复已移除软件**，点击对应项目的 **恢复**。原厂音乐和 BTPhone 固定优先显示。优先重新启用车机保留的系统包，必要时使用 U 盘本地恢复包，不重新从车机提取备份，也不自动更改默认应用或音源。

恢复的是程序本体，不能找回已经清除的应用数据。精简包需要恢复原厂软件时，请改用完整包。

### 查询桌面与 WePlay 新版

在安装页点击对应软件的 **查询新版**。需要车机能够访问 GitHub；下载后会检查包名、签名、版本和哈希。U 盘模式更新文件后仍需勾选安装；车机内运行模式可下载并安装。

### 不带 U 盘使用

在安装页点击 **安装管家到车机**。之后可从车机应用列表打开，使用卸载和两款软件的联网更新功能。车机内运行依赖已有的 `su` 授权；重启后仅开启 ADB，并不等于管家能取得提权权限。

## 常见问题

**权限通道未就绪 / `Connection refused`**
表示界面没有连上提权后台。先退出管家，将完整 U 盘重新插入并从原厂入口启动，等待扫描。若仍失败，查看 `/data/local/tmp/wm-usb-manager/bootstrap.log` 和 `worker.log`，确认后台是否成功启动。不同车机固件的原厂入口及权限条件可能不同。

**可清理显示 0 MiB，是存储空间用完了吗？**
不是。“可清理”只统计符合条件的临时文件；车机剩余空间请看安装页顶部。

**插入 U 盘后没有识别到软件**
检查是否解压到了根目录，APK 是否放在根目录下的 `apk` 文件夹，以及启动文件是否齐全。新增软件后点击刷新。

**安装失败或第三方软件功能异常**
先查看结果窗口中的具体原因。第三方软件的使用条件、测试状态及已知限制以对应 Release 和附带说明为准。
