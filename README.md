# 威马车机软件向导

面向已适配的威马 CQ1301 / Android 6.0.1 / ARMv7 车机，提供 U 盘自动弹出、软件移除、本地 APK 安装和原厂软件恢复。

## 下载

在 [Releases](https://github.com/naojiren/wm-usb-manager/releases) 下载完整包或精简包，并用附带 SHA-256 文件核对。

当前向导为 1.3.0；软件包内威马桌面为 wm23（1023），DiPlay / WePlay 为 perf24-control（68）。

| 包 | 安装软件 | 原厂恢复包 |
|---|---|---|
| 完整包 | 14 个 APK，前五项默认勾选，其余可选 | 附用户已有的 11 个本地恢复 APK |
| 精简包 | 仅 ADB 工具、DiPlay、威马桌面、ES 文件管理器、强制旋转 | 不备份、不附原厂恢复包 |

## 使用

1. 将 ZIP 内容直接解压到 FAT32 U 盘根目录，不再套一层文件夹；保留 factorymodel、certificates.xml、yfautorun.sh、yfautorun.md5 和 wm_manager。
2. 停车后插入已适配的车机 USB 接口，等待“威马车机软件向导”出现。页面先打开，再显示软件扫描状态。
3. 删除页默认选中仍安装的原厂百度地图和语音输入法。第三方软件另列一组，默认不选；选择后执行删除，或跳过删除进入安装页。
4. 安装页动态读取根目录 apk 文件夹，按 ADB 工具、DiPlay、威马桌面、ES 文件管理器、强制旋转的顺序列出五个默认项目。可取消选择，或添加其它 APK 后刷新，再一键安装。
5. 完整版可从“恢复已移除软件”调用附带的原厂包。精简版没有恢复页面；需要恢复时使用完整包。

再次插入 U 盘只打开向导，批量删除和安装都需要用户点击。APK 可自由增删，只扫描 apk 文件夹本层。安装时默认授予声明的运行时权限；悬浮窗、无障碍、默认桌面和默认输入法等特殊设置仍由用户在软件或系统设置中完成。

## 移除范围

原厂应用从当前用户移除并保留数据，不删除系统分区内原始 APK，不从车辆提取备份。移除原厂导航会失去其导航及对应仪表画面；移除语音输入法前会切换可用键盘，失败则取消删除。

原厂列表仅包含导航、输入法、娱乐及其卡片；车辆控制、倒车影像、仪表组件、TBOX、蓝牙、定位、升级和底层音频服务不在列表。第三方扫描与执行会保护系统应用、当前桌面、输入法、常驻基础服务、共享系统身份、启用的设备管理和无障碍服务。

## 手动更新

安装页可以手动查询 [威马桌面](https://github.com/naojiren/wm-launcher/releases) 与 [DiPlay](https://github.com/naojiren/diplay-wm/releases) 的公开 Release，下载经过哈希、签名、包名、版本和架构检查的 APK 到 U 盘；之后仍需要勾选并安装。

已知限制：当前向导 1.3.0 的 DiPlay 资产筛选要求文件名以 diplay-wm-ex5- 开头，perf24 Release 当前使用 WePlay-WM-EX5-perf24-armv7.apk，在线查询无法匹配该资产。Release 内已附 perf24 APK，可从本地安装。本次公开源码保持交付版本原样。

## 适配与权限

自动弹出与权限通道使用目标车机已有的原厂工程入口。设备必须实际支持该入口；通道失效时尝试已有 su，缺少可用入口时需重新插入 U 盘。此工具不会在不存在工程入口或 su 的设备上凭空获得 root。

权限通道与页面已用模拟 U 盘挂载检查；物理插拔和所有驾驶场景未作完整整车验证。请按目标固件实际情况使用。

## 源码与构建

- full：完整版本的 Android Java、资源、Manifest、启动程序和测试。
- lite：精简版本，保留删除和安装，去掉原厂恢复入口。
- usb-bootstrap：交付包的 U 盘启动脚本。
- tools：可移植构建和策略测试入口。
- docs：软件清单、来源哈希、构建及检查说明。

应用代码、资源和启动程序与本地已交付版本核对一致。公开目录和公开 Release 去除了历史车辆调试资料、开发机路径、签名私钥和凭据；各 APK、启动文件和完整包原厂恢复包保持原交付内容。

构建使用 JDK 17、Android SDK Platform 36、Build Tools 36.0.0，运行目标仍为 Android 6 / API 23。见 [构建说明](docs/BUILD.md)、[检查记录](docs/VERIFICATION.md) 和 [第三方内容说明](THIRD_PARTY_NOTICES.md)。

本仓库公开源码，当前尚未指定源码许可证；公开可见不改变第三方 APK 和原厂文件的许可。
