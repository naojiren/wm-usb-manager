# 威马车机软件向导 1.4.0

本包包含威马桌面 wm31、WePlay perf32 扫描抑制修复测试版。

## U 盘使用
将包内文件解压到 U 盘根目录。插入后进入卸载页，第二步选择软件安装；桌面默认勾选安装到系统分区，可取消改为普通安装。系统副本校验成功后请手动重启车机。分区不可写、空间不足或签名异常会报错；普通安装已完成但系统写入失败时会明确显示部分完成状态。

第二步新增“安装向导到车机”。U 盘启动流程已经安装了向导 APK，此按钮确认其已安装并建立车机版工作目录，不复制任何配套 APK 或原厂备份。从车机应用列表打开向导时只显示卸载和两款软件联网更新安装；从 U 盘入口打开则显示完整 U 盘功能。独立向导 APK 不含任何配套软件。

## 车机版
车机版需要车机已有 su 权限并授权；不会凭空取得 root。每次启动尝试启动本地权限通道，重启后仍需已有 su。没有 su 时请使用 U 盘原厂启动入口。卸载页保护车辆服务、系统组件、当前桌面和正在使用的基础服务。车机版不附带恢复包，原厂软件仅从当前用户移除。

联网更新只查询 naojiren/wm-launcher 和 naojiren/diplay-wm 的 GitHub 最新正式 Release，确认后下载、校验哈希、包名、架构、签名和版本，再安装。支持 WePlay ARMv7 文件名；已安装版本高于公开发布时会阻止降级。perf32 是指定对话的测试版，并不代表已上传至 GitHub。桌面默认写入系统分区，可关闭开关。

界面采用蓝绿色导航、圆角卡片与大号触控按钮；处理进度和失败结果使用明显颜色。

## 验证范围
完整与精简版编译、APK 签名验证、199 项删除和更新策略断言通过。ZIP CRC、软件清单、两个目标 APK 的来源哈希、签名连续性以及其它软件和原厂包字节一致性已检查。未连接 ADB、未连接车辆、未同步 U 盘。系统分区写入、su 授权、实际界面显示与真实安装效果仍需停车后实车确认。
