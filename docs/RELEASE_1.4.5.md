# 威马车机软件向导 1.4.5（2026-10-25）

## 当前软件
- 威马桌面更新为指定“威马桌面”对话的wm32，0.1.0-wm32 / 1032，保持原签名及默认系统分区安装开关。
- DiPlay来自指定“WePlay”对话，最新仍为perf32扫描抑制修复测试版，文件与前包一致。
- 完整包删除两个旧高德：V7.1、V9.1后台自动仪表投屏测试2，以及WM-Amap-Instrument-Companion-1.0.44.apk。
- 完整包加入“高德_V9.1_仪表指引后台投屏_单APP测试9.apk”：9.1.0.600087，约129.4MiB，仪表指引与后台投屏合一，不需额外伴侣。具体前后台交接效果需实车确认，安装使用说明随包提供。
- 完整包加入QQ音乐车机版3.15.0.3，约79.2MiB，支持Android 6 / ARMv7。
- 完整包有14个安装APK和13个本地原厂恢复APK。高德测试9和QQ音乐默认不选。精简包只保留原有默认5个安装APK，桌面同步wm32，不包含高德、QQ音乐或原厂恢复包。

## 使用
退出旧向导，将新版完整解压到U盘根目录，再拔插U盘，通过原厂入口启动。向导版本1.4.5 / 1.4.5-lite，versionCode均为8。
覆盖解压不会删除U盘旧文件：请按“删除旧文件清单.txt”从旧U盘apk文件夹移除旧高德两包、仪表伴侣和旧wm31桌面，避免旧包继续被自由扫描。其余自行添加的APK可保留。只替换U盘文件不会卸载车机里已经安装的程序；不需要的已装伴侣可在第一步手动勾选移除。
默认安装项仍为ADB工具、DiPlay、威马桌面、ES文件管理器、强制旋转。其它按需选择。apk文件夹仍可自由增减后刷新。
延续1.4.4的轻量扫描、元信息缓存、选中后完整校验、临时文件清理及空间显示。清理保留备份和应用数据，0MiB可清理量不表示数据分区没有剩余空间。
