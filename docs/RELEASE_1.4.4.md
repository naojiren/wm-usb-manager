# 威马车机软件向导 1.4.4

## 本次更新
- 完整包移除“网易云音乐-4.3.1-经典版.apk”，保留网易云音乐车机版。完整包现在有15个安装APK、13个原厂恢复APK；精简包仍为默认5个安装APK，不含恢复包。删除U盘包中的APK不会卸载车机里已经安装的软件。
- 扫描阶段只读取APK元信息，缓存未改变的解析结果，不再对所有APK进行完整验签和SHA256读取。实际安装所选软件前仍校验扫描选择凭据、文件状态、包名、版本、完整内容及签名。软件列表不显示签名已验证的承诺，签名异常会在安装阶段阻止。
- 批量读取已安装软件信息，减少逐包查询；扫描完成显示数量和耗时。尚未进行实车性能计时，不承诺固定秒数。
- 清理不再限制文件必须超过24小时，车机时间异常也不会把识别文件全部排除。扩充已识别的测试APK、调试日志、截图，以及向导遗留的selected.apk、restore.apk和bootstrap.apk三个安装中转包。
- 清理只作用于已列出的固定范围，不清空目录。操作前复核文件变化、进程引用和文件类型；备份、回滚文件、未知文件、应用数据以及正在使用的文件保留。
- “读取失败/未统计”和“没有可识别清理项”分别显示。显示顶层保留备份及未分类文件大小，避免读取失败时误显示0MiB。空间耗尽不意味着一定存在可删除的临时文件，已安装软件、应用数据、目录和备份可能占用其余空间。

## 更新与测试
退出旧向导，覆盖解压到U盘根目录，拔出再插入，通过U盘入口重新启动，以更新向导及root进程。
覆盖解压不会自动删除旧U盘文件：请同时删除旧U盘apk文件夹中的“网易云音乐-4.3.1-经典版.apk”，否则自由扫描仍会识别旧文件。其它自加APK可保留。
第一步先确认待清理文件清单，再按需勾选；清理与删除一起执行。第二步显示数据分区实际剩余空间，安装仍需要中转、解压及系统预留空间。
向导两版versionCode均为7，版本1.4.4 / 1.4.4-lite。完整包高德V9.1仍为后台仪表投屏测试2，桌面wm31和WePlay perf32保持原文件。
两版编译和签名连续性检查、337项策略断言通过，含元数据缓存失效、选择凭据/身份校验、最近/未来时间文件、固定中转路径及备份保留。ZIP CRC及文件哈希通过。实际扫描耗时与清理释放量由用户实车测试，本次未同步U盘、未操作车机。
