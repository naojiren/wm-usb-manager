# 威马车机软件向导 1.4.6（2026-10-25）

## 本次修改

1. 完整包内高德与用户提供的“高德_V9.1_仪表指引后台投屏_测试11.apk”逐字节一致，SHA-256：`c8fb3f9b543cacdff1b59d2bead0e7add7a5f63c7f1fe7a44d498e378d38b2e0`，135684304字节。只包含这一份高德，不含独立仪表伴侣。
2. 第二步选择高德安装时，在校验APK及兼容性后、实际安装前自动执行Android应用数据清理。收藏、账号、设置、离线地图可能丢失，请先保存所需内容。未选高德时不清理；其它软件的数据不受影响。清理失败即停止该项安装，并显示原因；新装且没有旧高德记录时跳过清理。清理与安装结果写入向导操作记录。
3. WePlay/DiPlay更新检测按APK文件名中perf后面的数字比较，例如perf32高于perf22、perf100高于perf99；相同perf不提示升级，线上perf小于本地时禁止更新覆盖。查询最近100条已发布Release（含测试版、不含草稿），选择其中可用ARMv7 APK的最大perf；发布日期和标签顺序不替代perf数字。相同perf的不同文件不作为升级。未标注perf的本地文件会明确提示无法比较，仍可下载安装并校验。桌面继续按原正式发布来源查询，保留包名、签名、哈希、架构及Android版本检查。
4. 高德卡片显示红色数据清理提醒，安装进度和结果显示数据清理状态。高德测试11使用准确名称，不再只显示通用后台投屏测试版。

## 关于此前的安装失败

`INSTALL_FAILED_UPDATE_INCOMPATIBLE`表示旧包与新包的签名冲突。清除应用数据不会改变旧包签名；如仍有该报错，需要完整卸载冲突的旧高德，再安装测试11。本版会明确提示，不会自动卸载旧应用或删除系统分区文件。若旧版是系统应用或仅对当前用户移除，应先检查残留包记录。无需反复清理数据尝试。

## 包内容与使用

向导版本1.4.6 / 1.4.6-lite，versionCode均为9，签名延续前版。
完整包有14个安装APK、13个本地原厂恢复APK；威马桌面wm32、WePlay perf32、QQ音乐等附带软件与上一完整包逐字节一致。高德测试11与附件一致。精简包只保留原有5个默认软件，不含高德、QQ音乐或原厂恢复包；用户自行加入高德APK后，安装时同样自动清除其应用数据。
默认安装项仍为ADB工具、DiPlay、威马桌面、ES文件管理器、强制旋转；高德与QQ音乐默认不选。apk文件夹可以自由增减，再点刷新。

请先退出旧向导，将新版完整解压到U盘根目录，再拔插U盘，通过原厂入口重新启动，以同时更换向导界面及后台处理程序。覆盖解压不会删除旧文件，请按照“删除旧文件清单.txt”清理旧APK；其他自行添加的APK可保留。只复制manager.apk而不重新通过U盘入口启动，可能继续使用旧后台程序。

高德V9.1仍在测试中，如无法使用，请使用上一1.4.1完整包中的V7.1；降级可能需先卸载V9.1，并保存需要的数据。
