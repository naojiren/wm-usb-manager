# 检查范围

- 完整版应用源码、资源和启动程序逐项与已交付源码包及本地源文件一致性核对。
- 完整版、精简版 manager.apk 分别与本地已交付 APK 哈希核对。
- 两种版本的策略测试各包含删除、受保护组件、路径/符号链接、五类默认软件、在线资产来源和哈希格式检查。
- 公开完整包含 14 个 APK，精简包含 5 个 APK；所有运行载荷与原本地包逐项核对。两种 ZIP 均检查 CRC 和文件清单 SHA-256。
- 已交付的界面字号、先弹出再扫描、删除/安装进度颜色、第三方扫描、本地恢复和安装后恢复启用等检查沿用 1.3.0 交付记录。

公开导出与上传过程没有连接车机、批量安装软件、删除原厂应用或同步 U 盘。原始车辆诊断、截图和开发机配置不进入公开仓库或公开 Release。

源文件哈希与 manager.apk 哈希见 source-provenance.json。GitHub Actions 额外编译两种版本并执行策略测试；未签名 CI 构建不会替代 Release 内的原签名 APK。
