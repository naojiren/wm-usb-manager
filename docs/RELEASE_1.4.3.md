# 1.4.3 扫描兼容修复

修复 Android 6 车机 root 扫描进程读取系统设置时的“Unable to find app for caller ... when getting content provider”错误。空间读取改用系统 settings 命令，不再由扫描进程直接通过 ContentResolver 访问 Settings Provider。
容量读取和预留阈值读取独立降级：阈值读取失败时继续显示实际剩余/总空间，提示“系统预留暂不可读”；整个空间读取失败时提示空间暂不可用，不中断软件扫描。
扫描失败与权限通道连接失败分别显示，记录具体错误，不再把全部扫描错误都提示成U盘或权限恢复问题。

## 测试方法
1. 退出旧向导，将新包解压到U盘根目录，覆盖同名文件。
2. 拔出再插入U盘，通过原厂U盘入口重新启动。此步骤会更新已安装向导并重启其root权限进程；单纯点旧界面的刷新无法更新旧进程。
3. 等待第一步完成扫描，然后进入第二步查看空间。若仍失败，请记录新版界面中的完整错误。
