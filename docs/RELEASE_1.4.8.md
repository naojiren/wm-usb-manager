# 威马车机软件向导 1.4.8（2026-10-27）

## 本次修改

- 删除列表加入BTPhone，实际包名为com.yftech.btphone，默认勾选、用户可以取消。删除项下方红字提示“蓝牙电话与 CarPlay 的蓝牙音频冲突”。移除后蓝牙电话/拨号入口可能不可用；不删除com.yftech.btservice或其它底层蓝牙、车辆服务。
- 完整包恢复页固定优先显示“原厂音乐”和“BTPhone”，即使当前已安装也可点击重新启用。优先恢复车机保留的系统包，必要时使用已有本地原厂APK；不从车辆重新提取备份。新增BTPhone恢复APK，原厂音乐备份沿用原文件。
- 两个包的ADB工具替换为用户提供的adb_toggle.apk，同包名com.car.adbswitch、同签名，仍为默认安装项。旧adb工具.apk不再包含在新版包内。
- 安装高德前核对旧包签名。普通高德签名不一致时，完整卸载旧高德及应用数据后安装已校验的新APK；同签名继续原数据清理流程。若系统在实际安装时才返回INSTALL_FAILED_UPDATE_INCOMPATIBLE，只处理一次冲突并重试一次。卸载失败、卸载后仍有包记录、系统应用、多个用户或用户状态无法确认时停止，不反复卸载。

## 重要说明

高德安装会清除收藏、账号、设置和离线地图等应用数据。签名冲突时会完整卸载旧高德，请先保存所需内容。只处理被选中的com.autonavi.amapauto；其他应用不会套用此重装流程。系统内置高德不会被自动删除，请使用匹配签名的软件包。原厂BTPhone的常规删除仍只对当前用户移除并保留数据，和高德完整重装是不同操作。

## 包内容

向导1.4.8 / 1.4.8-lite，versionCode均为11，签名延续前版。完整包14个安装APK、14个本地原厂恢复APK；精简包5个默认安装APK，无原厂恢复包和恢复页面。精简包也有BTPhone删除项，需要恢复时使用完整包。独立车机模式继续仅提供卸载及桌面/WePlay联网更新，不携带恢复包。
附带威马桌面wm32、WePlay perf33音频与蓝牙测试版、高德V9.1单APP测试12及其他APK沿用2026-10-26本地包，只有ADB安装包和向导程序更新；原厂恢复包增加BTPhone。高德与QQ音乐仍默认不选。安装默认项仍为ADB工具、WePlay/DiPlay、威马桌面、ES文件管理器、强制旋转；删除默认项现在为原厂百度地图、语音输入法及BTPhone，均可取消。

## 使用

退出旧向导，将新版完整解压到U盘根目录，再拔插U盘，从原厂入口启动，使界面和后台一起升级。覆盖解压不会删除旧APK，请从U盘apk文件夹删除旧“adb工具.apk”（见删除旧文件清单.txt），避免同包名重复选择；其他自加APK可保留。不要只安装manager.apk却继续使用旧后台。
高德V9.1和WePlay perf33仍是测试版本；高德不可用时可使用1.4.1完整包中的V7.1，切换前保存数据，降级可能需先卸载V9.1。
