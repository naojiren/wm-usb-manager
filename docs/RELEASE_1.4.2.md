# 威马车机软件向导 1.4.2

## 本次改动
- 第一步增加“清理历史临时调试文件”，默认不选。显示待清理文件名、数量及预计可释放空间；选中后与删除任务一起执行，清理优先。
- 仅识别 /data/local/tmp 顶层超过24小时的旧 DiPlay、WePlay、威马桌面测试 APK 和对应日志。保留备份/回滚文件、其它未知文件、子目录、向导工作目录、应用数据、符号链接及正在使用的文件。扫描后变化的文件跳过。不是清空整个临时目录；实际释放空间以结果为准。
- 软件扫描覆盖当前用户全部已安装包；原厂可选软件、第三方软件及受保护软件分组显示，带包名。系统、车辆服务以及尚未核实用途的程序展示但不可删除。
- 增加“原厂收音机”和“收音机桌面卡片”两个非默认删除项。删除收音机将失去原厂收音机入口及播放功能，底层收音机/音频服务保留。
- 安装页顶部固定显示 /data 剩余/总容量、扣除系统低空间预留后的参考空间。进入安装页、刷新、每次清理或安装完成后更新；读取失败明确显示不可用。
- 修复完整包原厂恢复：Android 6 重新安装 APK 返回 Success 后仍可能保留 installed=false。优先恢复现有原厂程序到用户0，再启用；必要时用 U 盘本地备份安装，再恢复用户状态，并核实实际可用状态。

## 使用
将所选 ZIP 全部解压到 U 盘根目录，插入车机启动。请通过新包的 U 盘入口启动，以更新向导及权限进程。两版向导均为 versionCode 5，完整版 1.4.2 / 精简版 1.4.2-lite。apk 文件夹仍可自由增减，刷新后重新扫描。
完整包保留16个安装APK和13个原厂恢复APK；精简包仅含原先默认的5个安装APK，不附原厂恢复包、无恢复页。安装默认项仍为 ADB工具、DiPlay、威马桌面、ES文件管理器、强制旋转。
高德V9.1与V7.1二选一。V9.1包130M，比V7.1增加36M；仪表伴侣1.0.44可选，配合V9.1使用。安装还需要中转、native库解压及系统预留空间，显示的空闲空间不是安装成功保证。
桌面仍为wm31，WePlay仍为perf32测试版。本次不替换这两个软件。桌面系统分区安装开关仍默认开启，成功后可手动重启生效。
独立车机版仅保留卸载/清理和两款软件的联网更新安装，要求已有su权限；不附配套软件或原厂备份。
